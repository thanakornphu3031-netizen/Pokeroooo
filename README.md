# Card Duel Online

เกมไพ่ประลองมือแบบออนไลน์ 2 คนต่อห้อง ใช้การจัดอันดับไพ่โป๊กเกอร์ 5 ใบเพื่อหาผู้ชนะ

**ข้อจำกัดที่ตั้งใจไว้:** ไม่มีการเดิมพัน, ไม่มีชิปเดิมพัน, ไม่มีเติมเงิน, ไม่มีถอนเงิน และไม่มีเงินจริง เป็นเกมไพ่เพื่อความบันเทิงเท่านั้น

## วิธีเปิดบนคอมพิวเตอร์

1. ติดตั้ง Node.js รุ่น LTS จาก https://nodejs.org/
2. แตกไฟล์ ZIP นี้
3. เปิด Terminal/Command Prompt ในโฟลเดอร์โปรเจกต์
4. รัน `npm install`
5. รัน `npm start`
6. เปิด `http://localhost:3000`

## วิธีเล่นออนไลน์กับเพื่อน

นำโปรเจกต์ไป deploy บนโฮสต์ที่รองรับ Node.js และ WebSocket เช่น Render หรือ Railway จากนั้นแชร์ URL ให้เพื่อน ทั้งสองคนเปิดเว็บ ใส่ชื่อ คนแรกกด “สร้างห้องใหม่” แล้วส่งรหัสห้องให้คนที่สองกรอกเพื่อเข้าร่วม

## กติกา

- แต่ละห้องมีผู้เล่น 2 คน
- แต่ละคนได้รับไพ่ 5 ใบ
- เมื่อทั้งสองคนพร้อม ระบบจะแจกไพ่
- กด “เปิดผลไพ่” เพื่อแสดงไพ่ของทั้งคู่และเปรียบเทียบอันดับ
- กด “เล่นรอบใหม่” เพื่อเริ่มรอบถัดไป

## หมายเหตุ

- โหมดออนไลน์ใช้เซิร์ฟเวอร์จริง ไม่ใช่แค่หน้าเว็บจำลอง
- โหมดบอทยังไม่ได้รวมในเวอร์ชันเริ่มต้นนี้
- การเชื่อมต่อออนไลน์จากคนละเครือข่ายต้อง deploy เซิร์ฟเวอร์ก่อน
